# Beyond Binary Metrics project page

Static project page at `/works/beyond-binary-metrics/`.

Sources: supplied paper `/Users/mark455/Downloads/sad.pdf`, CVPR SAD poster, HKU Scholars Hub record https://hub.hku.hk/handle/10722/375354, and visualization assets supplied from Safe_SMART. The result table is transcribed from the poster. Method equations and default parameters follow paper Sections 4.2–4.5, Equations (6–13). CCM is unconditional CVaR over the global severity distribution, including zero-severity collision-free instances; conditional CVaR is a separate statistic. OpenReview paper: https://openreview.net/pdf?id=agV9SBQcRk.

The displayed GIFs are Level 5 examples from different scenarios; they are not matched comparisons. No code release or repository link is advertised.

Preview through the homepage's Jekyll server, or run `python3 -m http.server 8000` in this directory.
